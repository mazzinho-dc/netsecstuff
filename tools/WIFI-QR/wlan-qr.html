Gäste-WLAN als QR-Code

SSID und Passwort eintragen, Karte drucken, hinstellen. Handy auf den Code halten, fertig — kein Buchstabieren und kein Abtippen mehr.

Netzwerk
Karte

Alles bleibt auf diesem Rechner. Der Code wird im Browser gerechnet, das Passwort wird nirgendwo gesendet und nirgendwo gespeichert — beim Schließen der Seite ist es weg. Aus dem Netz kommen nur die Schriften und die QR-Bibliothek, und die ist per SRI-Hash festgenagelt — würde sie auf dem CDN ausgetauscht, würde der Browser sie nicht laden. Einmal geladen, läuft die Seite auch offline weiter.
